Find local businesses without a website in any city

A free n8n workflow. Set a niche and a city, run it, and the businesses that have a Maps listing but no website end up in a Google Sheet — one row each, no repeats from earlier runs.

What it does

  1. Set niche, city and sheet name. Four values in one node: search text, city, region code and worksheet name.
  2. Search businesses in Google Maps. POST places:searchText on Places API (New) with a narrow field mask (13 fields), page size 20, up to 3 pages per run.
  3. Flatten. One row per business, with the phone, the address and a clean city column.
  4. Deduplicate across runs. Removes businesses already saved in earlier executions (history 5000).
  5. Keep only the ones with no website. A single filter on websiteUri.
  6. Append to Google Sheets. 14 columns; the discarded branch ends in a NoOp so the run stays readable.

The 9 nodes

  • Run every day at 08:00
  • Run manually (test with this one)
  • Set niche, city and sheet name
  • Search businesses in Google Maps
  • Flatten results into one row per business
  • Skip businesses already saved in earlier runs
  • Keep only businesses with no website
  • Append rows to Google Sheets
  • Discarded: this business already has a website

The honest limit: the test uses a recorded mock of the Places response, so it proves the logic (pagination, flattening, deduplication, filter, columns) — not what Google will answer for your city. For that you need your own key and your own first run, which costs a few cents.

Install

  1. Create a Google Places API (New) key with billing enabled in Google Cloud Console and enable Places API (New).
  2. In n8n: Import from file → the JSON below.
  3. Create an HTTP Header Auth credential with header X-Goog-Api-Key and your key as the value, and select it in the Search businesses in Google Maps node.
  4. Connect your Google Sheets account in Append rows to Google Sheets and pick the spreadsheet.
  5. Open 1. EDIT HERE and set niche, city, region and sheet name. Run the manual trigger first; the daily trigger stays off until you are happy with the list.
