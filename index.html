What these tools are not

You bring your own Google Places API (New) key with billing enabled, so Google bills your account (the first requests each month are free; a run of 3 pages is a few cents). Nothing here resells or caches Google data, and no personal data is collected: only what the Places API returns for a business.

What is not free. These two tools stop where the selling starts: they find businesses with no website, but they do not score them, write the pitch, or keep the pipeline. That is the B2B Revenue Autopilot Kit: a scoring rubric, the prompts, first-contact templates in English and Spanish, an API cost guide, a pipeline/CRM server and a commercial licence.

Why we publish them

Because the hard part of prospecting is not the idea, it is the plumbing that works twice in a row: the field mask that does not overbill, the pagination cap, the deduplication between runs, the export that opens in Excel. We publish that part free — including the exact test output — so you can check it before you trust it.
